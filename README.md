# Interactive To-Do List App

A responsive task management web application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using browser localStorage
- Responsive layout for desktop and mobile
- Task counter showing completed tasks

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Add, complete, or delete tasks.

## Project Purpose

This project was developed as part of my Frontend Development Internship to practice JavaScript DOM manipulation, event handling, local storage, and responsive web design.
